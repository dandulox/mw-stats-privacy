MW Stats – Privacy Policy

Last updated: 26 September 2026 · v6.13 · Deutsche Fassung unten

Who we are

MW Stats is a browser extension by Fomio (makerworld.com/@fomio). It is an independent project and is not affiliated with Bambu Lab or MakerWorld.

What data the extension processes

  • MakerWorld page data: while you browse makerworld.com, the extension reads the data the page already loads – for example model titles, tags, download, like and print counts, search results, feed contents and Creator Center figures.
  • Your MakerWorld account identifier: the user ID and handle of the logged-in account, used only to recognise your own models.
  • Your settings: language, sync interval and display options.

The extension does not read passwords, login tokens, payment data, messages or browsing activity outside makerworld.com.

Where the data is stored

All data is stored locally in your browser (Chrome extension storage and IndexedDB) by default. Since version 6, public model statistics can additionally be shared with Fomio's own server (see "Public data sharing" below) – everything else stays local, and this sharing is off unless you turn it on.

Public data sharing (optional, "Use & Share Public Data")

In the settings there is a single switch. When it is on, the extension periodically sends publicly visible model metrics – model ID, download/like/print/collection/comment/rating/boost/view counts and tags – to Fomio's API at api.fomio.de (encrypted via HTTPS), and in return you can see aggregated statistics contributed by other installations (e.g. community trend charts). When it is off ("Stay local"), nothing is sent and nothing is fetched – the extension behaves exactly as a purely local tool.

What is never sent, regardless of this setting: your MakerWorld login/session, account details, Creator Center figures, or anything else that is not a publicly visible model statistic. On first use, the extension generates a random installation ID and a matching secret and stores both only in your browser; requests to the API are identified by these, not by your MakerWorld account, name, or email. Neither value can be used to identify you personally; they exist only so the server can tell installations apart, rate-limit abuse and judge how trustworthy submitted data is.

Points data sharing (optional, separate opt-in, "Points & Rewards")

This is a second, independent switch from public data sharing above, off by default. MakerWorld does not publish how many points a download/print/boost is worth; if you turn this on, the extension helps build a community-wide estimate. With it on, and only then, the extension reads:

  • your own points totals from MakerWorld's /points page (overall, regular, exclusive, boosts),
  • individual point transactions from the transactions tab of that page (which model, which day, how many points – also fetched periodically in the background so you don't have to page through it yourself), and
  • the lifetime points/downloads/prints summary of a model when you open its page in the Creator Center ("Model Data").

These, plus the IDs of your own models, are sent to api.fomio.de (HTTPS) the same way as the public model metrics above – identified only by the same random installation ID, never by your MakerWorld account. Never sent as part of this: your name, handle, or any message/account data beyond the points figures listed. With this switch off, the extension does not read these pages at all, not even locally.

Optional automation

If you turn the automation on, the extension opens pages of makerworld.com in a single background tab (for example your own uploads, the Creator Center or the home feeds), reads the data shown there and closes the tab again. It is switched off by default, you choose the steps and the schedule, and it never opens any other website.

Network requests

The extension makes requests to makerworld.com (to load your own published models and missing tags of models shown to you, using your existing session, like the website itself does) and, only if you enabled public data sharing and/or points data sharing, to api.fomio.de as described above.

No tracking, no selling

MW Stats contains no analytics, advertising or tracking code. Data is never sold, shared with third parties, or used for any purpose other than showing you (and, for the data you choose to share, other users) statistics.

Your control

In the extension settings you can export all data as JSON, delete market data, delete everything, or switch public data sharing on or off at any time. Uninstalling the extension removes all locally stored data (previously shared public model statistics remain on the server, since they are aggregate/anonymous by design and not tied to your identity).

Contact

Questions: via makerworld.com/@fomio or the contact form on this website.

This website (the MW Stats landing page)

The above sections describe the browser extension. This website (where this policy is linked from) is a separate, static promotional page and processes data of its own, kept intentionally minimal:

  • Anonymous, cookie-less analytics: when you load the page, it sends a page-view event to api.fomio.de: the page path, and, if you arrived via a link, the domain only of the referring site (e.g. "google.com", never the full URL). When you click one of the "install" buttons (Chrome Web Store, Edge Add-ons, Firefox), which store it points to is recorded the same way. No cookie, IP address, or browser fingerprint is stored, and nothing is linked across visits or devices – each event is a standalone, anonymous data point used only to see how many people visit and which links they came from. These events are automatically deleted after 180 days.
  • Contact form: if you use the contact form, the name, email address and message you enter are sent to api.fomio.de and stored so we can read and reply to your message. They are visible only to Fomio's admin panel (password + two-factor protected), are never sold or shared with third parties, and are kept until the request is resolved or you ask us to delete them (via the same contact channel).

Datenschutzerklärung (Deutsch)

MW Stats ist eine Browser-Erweiterung von Fomio und ein unabhängiges Projekt ohne Verbindung zu Bambu Lab oder MakerWorld.

Verarbeitete Daten: Daten, die makerworld.com beim Surfen ohnehin lädt (z. B. Modelltitel, Tags, Downloads, Likes, Prints, Suchergebnisse, Feeds, Kennzahlen im Creator Center), die Nutzer-ID und der Handle des eingeloggten Accounts (nur um eigene Modelle zu erkennen) sowie deine Einstellungen. Passwörter, Login-Tokens, Zahlungsdaten, Nachrichten oder Aktivitäten außerhalb von makerworld.com werden nicht gelesen.

Speicherung: standardmäßig ausschließlich lokal in deinem Browser. Seit Version 6 können öffentliche Modell-Kennzahlen zusätzlich mit dem Fomio-Server geteilt werden (siehe „Teilen öffentlicher Daten" unten) – alles andere bleibt lokal, und diese Freigabe ist standardmäßig ausgeschaltet.

Teilen öffentlicher Daten (optional, „Use & Share Public Data"): In den Einstellungen gibt es einen einzelnen Schalter. Ist er an, sendet die Erweiterung öffentlich sichtbare Modell-Kennzahlen – Modell-ID, Downloads/Likes/Prints/Sammlungen/Kommentare/Bewertungen/Boosts/Views sowie Tags – verschlüsselt (HTTPS) an die Fomio-API unter api.fomio.de, und im Gegenzug siehst du aggregierte Statistiken anderer Installationen (z. B. Community-Trends). Ist er aus („Stay local"), wird nichts gesendet und nichts abgerufen – die Erweiterung verhält sich wie ein rein lokales Werkzeug.

Unabhängig von dieser Einstellung niemals übertragen: dein MakerWorld-Login bzw. deine Session, Account-Details, Creator-Center-Kennzahlen oder alles, was keine öffentlich sichtbare Modell-Kennzahl ist. Beim ersten Gebrauch erzeugt die Extension eine zufällige Installations-ID mit passendem Geheimnis und speichert beides nur lokal in deinem Browser; Anfragen an die API werden darüber identifiziert – nicht über deinen MakerWorld-Account, Namen oder E-Mail. Beide Werte lassen keinen Rückschluss auf deine Person zu; sie dienen ausschließlich dazu, Installationen zu unterscheiden, Missbrauch zu begrenzen und die Vertrauenswürdigkeit gemeldeter Daten einzuschätzen.

Teilen von Punkte-Daten (optional, eigener, separater Schalter, „Punkte & Belohnungen"): Das ist ein zweiter, unabhängiger Schalter, standardmäßig aus. MakerWorld veröffentlicht nicht, wie viele Punkte ein Download/Print/Boost bringt; ist dieser Schalter an, trägst du zu einer gemeinschaftlichen Schätzung bei. Nur dann liest die Erweiterung: deinen eigenen Punktestand von der /points-Seite (gesamt, regulär, exklusiv, Boosts), einzelne Punkte-Buchungen aus dem Transaktionen-Reiter dieser Seite (welches Modell, welcher Tag, wie viele Punkte – auch aktiv im Hintergrund nachgeladen), sowie die Lifetime-Zusammenfassung eines Modells, wenn du dessen Seite im Creator Center („Model Data") öffnest.

Diese Werte sowie die IDs deiner eigenen Modelle werden – genau wie die öffentlichen Modell-Kennzahlen oben – verschlüsselt an api.fomio.de übertragen, identifiziert nur über dieselbe zufällige Installations-ID, nie über deinen MakerWorld-Account. Nie übertragen werden dabei: dein Name, Handle oder sonstige Account-/Nachrichtendaten über die genannten Punkte-Werte hinaus. Ist der Schalter aus, liest die Erweiterung diese Seiten gar nicht mit, auch nicht rein lokal.

Optionale Automatisierung: Wenn du die Automatisierung einschaltest, öffnet die Erweiterung Seiten von makerworld.com in einem einzelnen Hintergrund-Tab (z. B. deine Uploads, das Creator Center oder die Startseiten-Feeds), liest die dort angezeigten Daten und schließt den Tab wieder. Sie ist standardmäßig aus, du legst Schritte und Zeitplan selbst fest, und es werden keine anderen Websites geöffnet.

Netzwerkanfragen: an makerworld.com (eigene Modelle und fehlende Tags angezeigter Modelle, gedrosselt, mit deiner bestehenden Sitzung) sowie – nur bei aktivierter Freigabe öffentlicher Daten und/oder Punkte-Daten – an api.fomio.de wie oben beschrieben.

Kein Tracking, kein Verkauf: keine Analyse-, Werbe- oder Tracking-Dienste. Daten werden nie verkauft oder an Dritte weitergegeben.

Kontrolle: In den Einstellungen kannst du alle Daten als JSON exportieren, löschen oder die Freigabe öffentlicher Daten jederzeit an-/ausschalten. Beim Deinstallieren werden alle lokal gespeicherten Daten entfernt (bereits geteilte öffentliche Modell-Kennzahlen bleiben auf dem Server, da sie aggregiert/anonym sind und nicht mit deiner Identität verknüpft werden).

Diese Website (die MW-Stats-Landingpage)

Die obigen Abschnitte beschreiben die Browser-Erweiterung. Diese Website (von der aus diese Erklärung verlinkt ist) ist eine eigenständige, statische Werbeseite mit eigener, bewusst minimaler Datenverarbeitung:

  • Anonyme, cookie-lose Analyse: Beim Laden der Seite wird ein Seitenaufruf an api.fomio.de gesendet: der Seitenpfad und, falls du über einen Link gekommen bist, nur die Domain der verweisenden Seite (z. B. „google.com", nie die vollständige URL). Ein Klick auf einen der Installations-Buttons (Chrome Web Store, Edge Add-ons, Firefox) wird ebenso erfasst, nur welcher Store. Es wird kein Cookie, keine IP-Adresse und kein Browser-Fingerabdruck gespeichert, und nichts wird über Besuche oder Geräte hinweg verknüpft – jedes Ereignis ist ein eigenständiger, anonymer Datenpunkt, der nur zeigt, wie viele Personen die Seite besuchen und über welche Links. Diese Ereignisse werden automatisch nach 180 Tagen gelöscht.
  • Kontaktformular: Nutzt du das Kontaktformular, werden Name, E-Mail-Adresse und Nachricht an api.fomio.de gesendet und gespeichert, damit wir antworten können. Sie sind nur im passwort- und 2FA-geschützten Admin-Bereich von Fomio sichtbar, werden nie verkauft oder an Dritte weitergegeben und bleiben gespeichert, bis die Anfrage erledigt ist oder du uns (über denselben Weg) um Löschung bittest.
